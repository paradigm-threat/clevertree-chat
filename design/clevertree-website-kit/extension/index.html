INSTALLATION

Load unpacked.

  1. Obtain the built Clevertree extension folder containing its manifest.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode, choose Load unpacked, and select that folder.
  4. Open the extension from Chrome to access its side panel.
