Debate the site you’re on

Side-panel extension. One debate per domain. Empty until you write.

The extension opens a simplified Debate board for the active tab’s whole site (path collapsed). Visitor and topic IDs are issued by api.clevertree.chat; posts go through the same durable /api/chat path as the web demos.

Download extension (.zip)

Version 0.2.0 · Chrome, Edge, Brave, and other Chromium browsers · not on the Chrome Web Store yet

Install

  1. Download and unzip clevertree-chat-extension.zip.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and select the clevertree-chat-extension folder.
  5. Pin Clevertree Chat, then open the side panel from the toolbar icon.

What you get

  • Normalized page URL → server topic id
  • Board stays empty until you post
  • Live durable boards for the tab you’re on (starter topics + any URL)
  • Talks to api.clevertree.chat
