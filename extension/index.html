INSTALLATION

Load unpacked.

  1. Download and unzip clevertree-chat-extension.zip.
  2. Open chrome://extensions (or edge://extensions).
  3. Enable Developer mode → Load unpacked → select the clevertree-chat-extension folder.
  4. Or from this repo: sync room assets (bash scripts/sync_extension_room.sh) then load fronts/extension.
  5. Pin Clevertree Chat and open the side panel from the toolbar.
