Clevertree Chat is independent infrastructure: a shared IRC transcript and an optional SI panel in one reusable shell.

Host contract

Clevertree.chat uses only #web. Ordinary browser sites use #web with domain context. Product sites supply their own authorized channel; MyProblem.app collections are the primary mount example.

Integration boundaries

The host provides channel identity, connection state, transcript, composer transport and SI batch results. SI curates only — it does not vote, pick winners, or mint topic-index entries. Networker tools belong in Options and are off by default.

Locked rules

  • Queue every claim as soon as it appears; permanent filing only after batch accepts.
  • Topic index entries are human/admin only — never auto-mint from page paths.
  • SI curates and organizes only; people alone supply preference.
  • Rejected intake spam never lands in the comments SoT.
