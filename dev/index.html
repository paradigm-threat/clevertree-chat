Near-future goals

  1. Chat UI in the wild — durable submit → comments git; fix /api/debate; always-on drain worker.
  2. Real batch SI pass — Groq/Bedrock/peers; end-to-end curator (file, summarize, ask on low confidence); publicize $/request.
  3. Internet investigations — fetch live counters (today: cite URL only, do not fetch).
  4. Anti-bot / anti-spam access — measure what blocks egress before wiring fetch into the curator.
  5. Human loop + spam court + URL associations — deliver asks; hide/contest; mirror canonicalization.

Locked rules (don’t undo)

  • Page path = topic. Never mint a key equal to the page slug.
  • File claims immediately; agreement does not suppress axes. Non-arguments → other.
  • Unwritten counters stay suggestions until someone writes them.
  • Low confidence → ask the owner; no private standing exceptions.
  • SI curates only: no votes, no winners, no sides — fair organization at a scale a human alone cannot keep.
