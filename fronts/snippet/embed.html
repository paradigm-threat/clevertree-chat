Embed Clevertree Chat

Paste a mount on any host page. Point data-api-base at the Intake chat host for live WebSocket updates.

<link rel="stylesheet" href="https://intake.myproblem.app/fronts/snippet/clevertree-chat.css">
<div
  data-clevertree-chat
  data-api="chat"
  data-api-base="https://intake.myproblem.app"
  data-topic="thc-legalization"
  data-guided="true"
></div>
<script src="https://intake.myproblem.app/fronts/snippet/clevertree-chat.js"></script>
