# Solo debate

A second person is optional. The first comment is enough for a debate with the AI.

The visitor states a position in their own words. The live path does not file that under a key of its own. With no chosen existing category, the post stays uncategorized until the batch. The batch may place it in one existing argument, in several, or in none. A new argument appears only when the post fits none of the keys already there. On each slot it does join:

- rewrites `position.md` as a short, emotionless restatement
- writes `questions.md` with the questions that would flesh the argument out
- writes `suggested-counter.md` with the opposing one-liner and a citation

The citation is the live URL of a counterpoint already published online. Phase 1 records that URL and does not fetch the page. The counter file stores the argument and the citation, not a snapshot of the page.

The opposing key is a suggestion. `national-security` does not exist as a directory beside `invasion-of-privacy` until some user writes the first words there. That user can be the same person, opening the other side, or someone else later. The curator does not author the opening post of either side.

Questions land on the section the user already started. They are not a new topic. An empty page stays empty until a person types, or, on the phone, until they talk. The spoken words are text by the time they are filed. The Android component asks the API for audio of the section. It does not write git.

When the section changes, the person who took part is told. See [subscriptions.md](subscriptions.md).
