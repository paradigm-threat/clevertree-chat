# Spill

Template case. One comment file. A new key only when a post does not fit the keys that already exist.

The topic is `flock-cameras`. The folders start empty. Nobody has to choose a category. A manual choice, when someone makes one, is only the starting slot. The batch may clean it up later.

## Posts

1. “Mass surveillance is necessary.”
2. “Are these cameras mass surveillance?”
3. “but it's illegal!”
4. “These cameras are illegal mass surveillance.”
5. “Are these cameras illegal?”

## What the batch does

Post 1 names privacy, and privacy is not a key yet. That post does not fit any existing key, so the batch mints `invasion-of-privacy` and files it there. It does not also mint `national-security`. “Necessary” is not a second argument. `illegal`, `legal`, and `other` stay absent.

Post 2 is a question, and questions are allowed unless the posted rules forbid them. It names mass surveillance, which already exists, so it joins `invasion-of-privacy`. It fits cleanly. No new key.

Post 3 does not fit privacy. The batch creates `illegal`, files that reply there, and poses a question on the new key. The reply is one file. It is not copied into a second body. No post yet answers the accusation of being illegal, so the batch cites a real counter: the Patriot Act, `https://www.congress.gov/bill/107th-congress/house-bill/3162`. That citation is a suggestion in `illegal/suggested-counter.md`. It does not create `legal`. `legal` waits until a person writes words that spill into it.

Post 4 names two axes, and both keys now exist. The one comment is listed from `invasion-of-privacy` and from `illegal`. It is not split into two comment bodies, and it does not open `legal`.

Post 5 names `illegal`. That key exists, so the question joins it. It is not dumped in `other`. No new key.

## Least resistance

Do not mint a key just to catch every sentence. Mint one when a post does not fit the keys that already exist. Posted rules can say otherwise. `Never open a new topic` stops a spill from opening a directory. `Do not ask questions` stops a question from opening one. A non-argument that fits nowhere stays uncategorized. A posted rule that forbids a new topic sends that spill to `other` instead of opening a directory. A question that names a real axis joins it when questions are allowed.
